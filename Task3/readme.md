Cписок проблем и рисков, которые связаны с планируемым ростом нагрузки

Проблемы:
1. ins-comp-settlement получает данные о продажах раз в сутки с задержкой 
2. Ошибки при взаимодействии между сервисами
3. При падении одного запроса к страховой, не удается обновить его для остальных

Риски: 
1. Не получения данных о продажах при падении запросов
2. Рост нагрузки, пиковая нагрузка раз в какое-то время не распределена равномерно 
3. Несогласованность данных в сервисах core-app и ins-comp-settlement
4. ins-product-aggregator при падении нескольких страховых, может не выдержать
5. Риск просадок доступности из-за одной ВМ постгри и одной зоны доступности
6. Риск создания дополнительных нагрузок от партнеров (нет rate-limit/квот)
